# Где искать основания: карта мест в текстах Бушуева

Дата: 2026-09-08. Спутник [смыслового разбора](bushuev-semantic-core-20260908.md).
Это навигация по источникам, не перечень установленных физических законов.
Содержание строки означает «автор говорит/показывает это здесь»; оценка вынесена
в смысловой разбор. Код места сохраняется при последующем уточнении оценки.

## Как пользоваться

- Для пособия B22 указаны две страницы: печатная / PDF. Например, 21 / 22 —
  на бумаге внизу стоит 21, а в просмотрщике надо открыть страницу 22.
- Для статьи B23 печатные страницы совпадают с номерами страниц полного PDF.
- Для HTML страниц нет. Указаны раздел, таблица/формула и, где полезно,
  технический номер блока. Эти номера наши, не авторская нумерация.
- Для B11 номера `pN` получены по XPath `.//p[not(ancestor::table)]` внутри
  единственного `div.field-item.even` автономной копии, начиная с 1, включая
  пустые абзацы. Для B07a, B07b, B08: `//p | //h1 | //h2 | //h3`, также с 1.
  Заголовок раздела и описание места позволяют найти фрагмент обычным поиском.

## Ранняя серия: постановка и размерный ресурс

<a id="b07a-model"></a>
**B07a-model.** Ч. 1, после обсуждения ограниченности модели; формулы (1)–(2),
блоки 58–72. Модель через потенциальную функцию и выбор масштабных коэффициентов.
Затем автор сопоставляет свойства с известным решением ампульной задачи.

<a id="b07b-product"></a>
**B07b-product.** Ч. 2, раздел о ресурсных трендах, формулы (3)–(5), блоки 36–50.
Переход от уравнения слежения к произведению факторов и движению по диагонали.

<a id="b08-coefficient"></a>
**B08-coefficient.** Ч. 3, первый раздел о балансе, формула (6) и первая таблица,
блоки 7–43. Здесь C явно ограничен степенью скорости; таблица содержит шесть k.

<a id="b08-missing"></a>
**B08-missing.** Ч. 3, раздел с тестовыми задачами, блоки 85–88. В примере
молниеотвода несовпадение трендов приводит автора к добавлению частоты.

Эти места нужны для установления предпосылок, а не для принятия исторической
реконструкции за прямое описание работы самого Бартини.

## B11: популяция, наследование и выбор

<a id="b11-frame"></a>
**B11-frame.** Введение, p10–13. Несколько возможных узких мест; исходная
потоковая модель предполагается уже построенной. Особями становятся измеряемые
свойства её элементов и взаимодействий.

<a id="b11-tracking"></a>
**B11-tracking.** Раздел о математическом базисе, формулы (1)–(3), p23–34.
Уравнение `K dz/dt=3xy−az` относится к удержанию X-элемента после озарения.
Затем автор переходит к размерному произведению; C назван размерным.
В формуле (2) HTML буквально напечатано `z=3xy−a=Cxy`; равновесие формулы (1)
при ненулевом a даёт `z=3xy/a`. Расхождение отмечено, исходный текст не исправлен.

<a id="b11-procedure"></a>
**B11-procedure.** Раздел о генетическом алгоритме, p38–48. Последовательность
от описания ситуации до селекции; функцию приспособленности автор выбирает по задаче.

<a id="b11-factors"></a>
**B11-factors.** Раздел «Пример», p63–80 и таблица 2. Десять факторов ампульной
задачи и размерные произведения. Шесть пар из длины, времени и температуры
дают S=2; две другие строки показывают S=−4 и S=4.

<a id="b11-fitness"></a>
**B11-fitness.** Там же, p82–87, таблица 3. В начальной популяции 34 адреса;
шести присвоено 5, остальным 1. Пять итераций выбраны как условие остановки.

<a id="b11-inheritance"></a>
**B11-inheritance.** p94–117, формулы (4)–(7), рисунок 3. Рулеточная селекция;
потомок — произведение размерностей; оценка потомка усредняет оценки родителей
и его исходную оценку. Совпадающие потомки объединяются с усреднением оценок.
Величины с объявленной автором нереализуемой размерностью заменяются случайно.

<a id="b11-winner"></a>
**B11-winner.** Последний абзац примера, p118, непосредственно перед заключением.
После пяти итераций первым назван `L¹T¹`, вторым — объёмный расход `L³T⁻¹`.
Численные итоговые оценки, последовательность поколений и seed не предъявлены.

<a id="b11-limits"></a>
**B11-limits.** Заключение, p120. Автор положительно оценивает результат, но
прямо называет проблемой предварительное ранжирование. Предлагает поощрять
свойства ресурсов, имеющихся в избытке. Это не то же основание, что участие
в процессе, использованное при назначении начальных пятёрок.

## Что действительно проверено при этом чтении

Тексты трёх ранних частей прочитаны с локальных HTML-снимков; таблица и диаграмма
трендов дополнительно просмотрены как изображения. B11 прочитан целиком, включая
таблицы и все шесть изображений. B22 и B23 читались в предыдущих проходах и
адресно перепроверялись здесь; это не новая сплошная визуальная проверка всех страниц.
В текущем проходе отдельно проверена формула Холла на PDF-странице 22 B22.

Три ранние HTML-страницы сохранены без изменения ответов сайта; автономные копии
содержат встроенные авторские GIF. Декоративные изображения и активные элементы
страниц исключены из производных копий; внешние ссылки оставлены внешними.
Посимвольное сравнение текста после разбора и повторного UTF-8 чтения прошло,
число таблиц сохранено, все оставшиеся изображения встроены. Полный визуальный
просмотр браузерной вёрстки автономных копий не выполнен.
Размеры и SHA-256 находятся в [дополнительном манифесте](sources/literature-20260908/early-articles-manifest.json).

Расчётные утверждения проверяет [небольшой скрипт](bushuev-semantic-checks.py).
Он не воспроизводит пять поколений авторского алгоритма и не проверяет физическую
работоспособность кандидатов. Ссылки на другие работы внутри источников — не
свидетельство того, что эти работы прочитаны.
