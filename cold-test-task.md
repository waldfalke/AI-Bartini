# Холодный тест — задание

Реши инженерно-материаловедческую задачу **методом LT-Бартини**. Скилл в этом
проекте — найди `SKILL.md` и файлы, на которые он ссылается, и следуй им. Опирайся
**только** на файлы скилла. Не подгоняй под заранее «известный» ответ — пусть
результат выпадет из метода.

## Задача

Мастер делает мелкие **художественные изделия из многоцветного бетона** (украшения,
небольшие объекты). Цель — чтобы цвета **не сливались в грязь**, а образовывали
**объёмный узор** (как мрамор / скальола): на **любом распиле** изделия видна
многоцветная картина — прожилки, цельные вкрапления, разводы. Это **не послойная
заливка** (плоские слои), а цвет, распределённый по всему объёму.

Условия и жалобы мастера:
- цвета при замешивании и укладке норовят **перемешаться в однотонную кашу**;
- изделие должно быть **одним прочным монолитом** — тонкие части (ушки, перемычки)
  не должны откалываться и ломаться;
- поверхность нужна **чистая, без раковин и пузырей** (это арт-объект);
- всё **вручную**: без промышленного вакуумного смешивания, без термокамеры, без
  точной дозировки;
- хочется **управлять резкостью границ** — где-то чёткие домены, где-то мягкие
  ореолы / марборность;
- какие **компоненты и красители** брать и как **вести процесс**?

## Что выдать

1. Прогон по шагам метода (размерности `LᵐTⁿ`, тренды/цвета, `S=m+n`).
2. Матрицы баланса, где применимо.
3. Сводная таблица: противоречие → тип/тренд → икс-элемент (или вывод) →
   интерпретация → статус.
4. Честная самооценка: где метод сработал, где споткнулся, и — **важнее всего** —
   чего не хватило в файлах скилла, чтобы пройти путь. Прямо, скилл не выгораживать.
