# AI-Bartini

Скилл для Claude Code: **LT-метод Бушуева–Бартини–Кузнецова** — разрешение
инженерных и изобретательских противоречий на уровне физических размерностей
длины и времени (`LᵐTⁿ`).

В отличие от АРИЗ, метод работает с несколькими факторами сразу и опознаёт
икс-элемент по его физической размерности. Главное — он указывает не одно решение,
а **тренд физически-эквивалентных рычагов**, среди которых есть неочевидные.

## Использование

Открой проект в Claude Code и сформулируй задачу как противоречие — скилл
активируется по фразам вроде «реши по Бартини», «LT-метод», «найди неочевидное
решение через размерности». Подробности — `CLAUDE.md` и
`.claude/skills/lt-bartini-method/SKILL.md`.

## Что внутри

- **Метод** — `SKILL.md` (логика + контракт), данные в `bartini-table.md`,
  `si-to-lt.md`, `trends.md`.
- **7 разобранных примеров** — от классики Бушуева (запайка ампул, горячий шлак,
  молниеотвод) до неклассических доменов (упаковка цемента, лопатка турбины,
  термодинамика информации, CAP-теорема).
- **Самонаблюдение** — `antipatterns.md` (сбои работы) и `epistemics.md` (границы
  доверия к выводам: что заземлено, где риск «зеркала», какие вопросы открыты).

## Происхождение

Восстановлен из статей А.Б. Бушуева (metodolog.ru, 2007–2008) на основе работ
Р.О. Бартини и П.Г. Кузнецова.
