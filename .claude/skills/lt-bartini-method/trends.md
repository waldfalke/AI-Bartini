# Тренды, гены, цвета и движение по таблице

Изображение-первоисточник трендов ВПР: `vpr-trends-source.png`.

## Три тренда и три гена

- **Пространственный тренд** = строка `Tⁿ = const`. Соседняя ячейка — умножение на
  **ген длины `L⁺¹`** («быть совокупностью линий»: точка→линия→поверхность→объём).
- **Временной тренд** = столбец `Lᵐ = const`. Соседняя ячейка — умножение на
  **ген времени `T⁺¹`** (вниз) / `T⁻¹` (вверх). Связь интегро-дифференциальная
  (ускорение → скорость → длина).
- **Тренд ВПР** = **диагональ** слева-снизу направо-вверх. Соседняя ячейка —
  умножение на **ген скорости `V = L¹T⁻¹`** (`V⁺¹` вправо-вверх, `V⁻¹` влево-вниз).
  Ключевой факт: `V` имеет `S = 0`, поэтому движение по диагонали **не меняет `S`**.

## Цвет тренда по `S = m+n`

| `S = m+n` | Цвет | Ген тренда |
|---|---|---|
| `0` | 🟡 жёлтый | `LⁿT⁻ⁿ` |
| `±1` | ⬜ серый | `LⁿT⁻ⁿ±1` |
| `±2` | 🔵 голубой | `LⁿT⁻ⁿ±2` |
| `±3` | 🟢 зелёный | `LⁿT⁻ⁿ±3` |
| `|S| ≥ 4` | ⬛ белый | вне трёхмерного пространства — не реализуется |

Ориентация: «верхний» тренд = `S < 0` (силовой полюс), «нижний» = `S > 0`
(расходно-кинематический полюс). Всего 7 реализуемых диагоналей (`S` от −3 до +3).

⚠️ **Цвет = тип тренда (по `|S|`), не его идентичность.** Одного цвета — ДВЕ
диагонали (кроме жёлтой `S=0`): верхняя `S<0` и нижняя `S>0`. **Конкретную диагональ
задаёт ЗНАК `S`, а не цвет.** Всегда пиши `S` со знаком (не «голубой», а «голубой
`S=−2`»); для наглядности помечай направление `↑` верхний (`S<0`) / `↓` нижний
(`S>0`) — тогда `🔵↑ S=−2` и `🔵↓ S=+2` не спутать. (Цвет по `|S|` — канон Бартини,
см. `vpr-trends-source.png`; знак — отдельный слой поверх него, цвета не переназначаем.)

⚠️ **Белая ячейка (`|S|≥4`) — сигнал, не тупик.** Если произведение факторов «И-И»
ушло за `|S|≤3` (бело, вне 3D) — это не «решения нет», а **«эта пара факторов не
реализуема в 3D → вернись на Шаг 2, пересмотри что мерить»**. Подбирай измеряемые
свойства так, чтобы их произведение оставалось в полосе `|S|≤3`. Без этой проверки
отбор факторов вырождается в копирование знакомого примера.

## Тренд как меню рычагов (откуда берётся неочевидное)

Найденный тренд — это **не одно решение, а ряд ячеек одного закона сохранения**.
Ближайшая ячейка (обычно на пересечении с объёмом `L³`) — очевидный икс-элемент.
Остальные ячейки того же тренда — **физически иные домены, размерно эквивалентные**:
геометрия, сила, частота, поле, поток и т.д. Чтобы вытащить неочевидное —
**пройди весь тренд** и прочитай, какой физический рычаг стоит в каждой ячейке
применительно к задаче. Это и есть генеративная сила метода.

⚠️ Размерная эквивалентность ≠ инженерная равноценность: «ток» и «полимер» на одном
тренде не значит, что они одинаково дёшевы/безопасны. Это направления для человека,
не готовые техпроцессы.

## Правило знака

Цвет/диагональ определяется по `S = m+n` от **канонической ячейки таблицы**
(положительный `L`, см. `bartini-table.md`). Знаковые флипы `L` в прозе Бушуева —
зеркало относительно `L⁰`, игнорируй: иначе `S` меняется и уходишь не на тот тренд.

## Экзотические ячейки — не впадать в ступор

- `L¹T¹` = **длительность расстояния**, `L⁰T²` = **поверхность времени** — это
  легитимные ячейки временных трендов, а не ошибка.
- **Отрицательные `k`** в балансе ресурсов (когда среди факторов есть температура)
  выводят на эти понятия. Чтобы не вникать — домножь логическую формулу баланса на
  ген скорости `Vᵏ` (`k > 0`): выход переоценится через привычный фактор того же
  тренда.
- `k = 0` допустимо («расход нагретого газа · V⁰ = расход холодной воды»).
- В дизайне эти ячейки читаются как рычаги «во времени»: разнести конфликтующие
  свойства по оси времени (например, свойство-сейчас vs свойство-потом).

## Баланс ресурсов: совпадение, расхождение, расщепление

`z = C·x·y`, где `C = Vᵏ`. Так как `V` имеет `S = 0`, `x·y` и `z` лежат на одном
тренде — поэтому перебор всех пар факторов проверяет единство тренда. Три исхода:

- **Совпадение** — все пары имеют общий S. Это размерная согласованность, не
  подтверждение одного физического явления. Проверь её арифметическую причину;
  полученный `z` остаётся кандидатом для предметного опознания.
  Пример: в ампульном разборе пары из факторов с S=1 неизбежно имеют S=2;
  выбор объёмной координаты даёт `L³T⁻¹`, но не независимые подтверждения механизма.
- **Расхождение через один «особый» фактор** — пары разлетаются, но сводятся
  доумножением на ген до целевого тренда. Ячейка-множитель = **недостающий фактор**
  (молниеотвод: `×L⁰T⁻¹` → частота). Лечится одним шагом; икс-элемент по-прежнему один.
- **Расщепление на 2+ устойчивые группы** — пары делятся по трендам по признаку
  «какой фактор участвует» (напр. все пары с теплопроводностью → один тренд, без неё
  → другой). Это **не ошибка и не один недостающий фактор**, а **несколько
  дополняющих икс-элементов, сосуществующих** (турбина: голубой `L³T⁻¹` поток
  охладителя + серый `L³T⁻⁴` поверхностный барьер = активная + пассивная защита).
  Диагностика: если «отщепляющий» фактор устойчиво уводит свою группу на отдельную
  диагональ — читай каждую диагональ как самостоятельный икс-элемент, не своди к
  одному силой. Пример — `examples/turbine-blade.md`.
