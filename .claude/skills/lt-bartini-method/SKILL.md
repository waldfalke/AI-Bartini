# LT-метод Бушуева–Бартини–Кузнецова

Разрешение противоречий на уровне физических размерностей в базисе длины `L [м]` и
времени `T [с]`. Конфликтующим факторам назначается размерность `LᵐTⁿ`; их
произведение «И-И» даёт тренд вещественно-полевых ресурсов (ВПР); икс-элемент
опознаётся по размерности найденной ячейки и описывается через её свойства.

Это **логика рассуждения, применяемая с суждением, — не чек-лист**. Шаги ниже —
естественные сочленения самого метода (по Бушуеву), а не нарративные фазы.

Применяй с [ограничениями вывода](limits.md): исторические названия и интерпретации
не заменяют физическое доказательство. Этот файл задаёт границу уверенности и при
более категоричной формулировке в учебном примере.

## Генеративная идея (зачем метод, а не просто ответ)

- Противоречие не лечится компромиссом — оно снимается **икс-элементом с
  определённой размерностью**.
- Метод указывает **не точку, а тренд** (диагональ ВПР). Ближайшая ячейка —
  очевидное решение. Остальные ячейки того же тренда — физически иные, но
  **размерно-эквивалентные рычаги** (другая физика, тот же закон сохранения).
  Тренд = меню рычагов. **Неочевидные решения живут на дальних ячейках того же
  тренда** — туда «химия-первой» интуиция не доходит.
- Метод работает с **несколькими факторами сразу**, а не с парой (отличие от АРИЗ).

## Что считать результатом

- **Очевидный икс-элемент** (ближайшая ячейка) — полноценный результат. Часто на
  нём и нужно остановиться: он формирует контекст и нередко решает задачу.
- **Дальше по тренду** — неочевидные/контринтуитивные рычаги. Это **не готовые
  решения, а кандидаты**: их человек обязан крепко обдумать (TRL, стоимость,
  риски, реализуемость). Не выдавай их за готовое и не обесценивай очевидное ради
  «креатива».
- **Сколько икс-элементов** — столько, сколько на тренде физически осмысленных
  ячеек применительно к задаче. Не фиксированное число.

## Ход рассуждения

0. **Список противоречий.** Явно от пользователя — взять как есть. Иначе выделить
   из задачи: компактная факторгруппа сильной связи → решающие факторы →
   контрастное «ИЛИ-ИЛИ». <!-- MODULE:STEP0 — заменяется наработками автора по
   агентному выявлению противоречий; интерфейс: текст задачи → список ИЛИ-ИЛИ. -->
   **Пред-чек (барьер высокий):** противоречие настоящее или **артефакт рамки**
   (ориентация, ярлык, фиксированная предпосылка)? Псевдо — **только** если
   *бесплатное переименование/поворот гасит конфликт БЕЗ изменения физики* (чашка
   «дна нет, верх запаян» → переверни). Тогда переформулируй/переориентируй,
   икс-элемент не ищи. Иначе противоречие настоящее → дальше (разрешимое икс-элементом
   либо требует сохранения баланса требований; см. `limits.md`). ⚠️ **Псевдо ≠ несомое:** оба «без икс-элемента», но
   псевдо — *конфликта нет* (роняешь ложную предпосылку), несомое — *конфликт
   неустраним* (держишь). Пред-чек различает, а не отговаривает работать (AP-13).
1. **«ИЛИ-ИЛИ».** Свойство `X` хорошо для `A`, плохо для `B`, и наоборот. Факторов
   может быть больше двух.
2. **Размерности.** Каждому фактору `LᵐTⁿ` через `si-to-lt.md` + `bartini-table.md`.
   Перевод механический; единственное суждение — *какое свойство мерить*. Если
   неочевидно — предложи варианты с обоснованием или спроси.
3. **Перемножение «И-И».** Показатели складываются → родительский элемент тренда
   ВПР; `S = m+n` → цвет/диагональ (`trends.md`).
4. **Движение по тренду.** По диагонали (ген скорости, `S` не меняется) до ячейки
   с осмысленным икс-элементом — обычно до пересечения с объёмом `L³`. Это
   очевидное решение.
5. **Баланс ресурсов.** Перебери пары факторов и сравни их тренды. Совпадение
   показывает общий S, но не подтверждает тождество механизмов: проверь, не следует
   ли оно из размерностей исходных факторов. При расхождении домножение до выбранного
   тренда порождает гипотезу недостающего фактора; его физический смысл и связь
   с задачей устанавливаются отдельно.
6. **Опознание.** Ближайшая ячейка = очевидное. **Пройди весь тренд** → остальные
   ячейки = неочевидные рычаги (разные физические домены) → кандидаты для человека.
7. **Формулировка.** Икс-элемент — через геометрию (`L`), время (`T`), физику.
   Вещество **не называется из таблицы**; конкретику опознаёшь по свойствам в
   контексте задачи.

## Гигиена мышления и речи (дисциплина, не запреты)

- **Числа.** Предпочитай выведенные или со ссылкой. Определения метода
  (`S = 0/±1/±2/±3`; `|m+n| ≤ 3` = трёхмерность) — это определения, не магия.
  Выдуманные пороги и доли — нет.
- **Спекуляция помечается спекуляцией.** Разделяй proven / speculative. Размерная
  эквивалентность ≠ инженерная равноценность: метод даёт направление, не техпроцесс.
- **Число решений — по физике тренда**, не по шаблону «ровно три».
- **Без выдуманных фаз и театра** поверх метода.
- **Очевидное — валидный результат.** Не раздувай выдачу ради видимости глубины.
