# Пример: запайка ампул → `L³T⁻¹` → проточная вода

Эталон Бушуева (ч.1–2). Результат метода совпадает с ответом из «Крыльев для Икара».

**ИЛИ-ИЛИ.** Пламя сильное → хорошая запайка, но перегрев лекарства; слабое → нет
перегрева, но плохая запайка. Факторы: длина оплавленного капилляра, температура
лекарства, время нагрева.

**Размерности.** Свойство изделия = высота ампулы `L¹T⁰`; свойство инструмента =
поверхность контакта пламени `L²T⁰`; икс-элемент по цепочке → объём `L³`.
Температура `L⁵T⁻⁴`, время `L⁰T¹`.

**И-И (родительский тренд).** Длина · температура: `L¹T⁰ · L⁵T⁻⁴ = L⁶T⁻⁴`,
`S = +2` → 🔵 нижний голубой.

**Движение по тренду.** Образ икс-элемента — `L³`. По голубой диагонали (`×V⁻¹`):
`L⁶T⁻⁴ → L⁵T⁻³ → L⁴T⁻² → L³T⁻¹`. Пересечение с временным трендом `L³Tⁿ` → `L³T⁻¹`
= **объёмный расход**.

**Баланс ресурсов** (выход `z = L³T⁻¹`):

| x | y | C=Vᵏ | z |
|---|---|---|---|
| Длина `L¹T⁰` | Длина `L¹T⁰` | `V¹` | `L³T⁻¹` |
| Длина `L¹T⁰` | Время `L⁰T¹` | `V²` | `L³T⁻¹` |
| Время `L⁰T¹` | Время `L⁰T¹` | `V³` | `L³T⁻¹` |
| Время `L⁰T¹` | Температура `L⁵T⁻⁴` | `V⁻²` | `L³T⁻¹` |
| Длина `L¹T⁰` | Температура `L⁵T⁻⁴` | `V⁻³` | `L³T⁻¹` |
| Температура `L⁵T⁻⁴` | Температура `L⁵T⁻⁴` | `V⁻⁷` | `L³T⁻¹` |

Все пары → один тренд. `C = Vᵏ` (`k=1` → линейная скорость надвижения горелки) —
недостающий третий фактор.

**Икс-элемент.** `L³T⁻¹` = объёмный расход = поток, имеющий объём, расходуемый и
распределённый по высоте ампулы (холодный снизу, горячий у капилляра). Опознаётся
как **проточная вода** (тепло/хладоноситель).
