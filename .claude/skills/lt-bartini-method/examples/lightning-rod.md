# Пример: молниеотвод → серый `S=−1`, расхождение → частота `L⁰T⁻¹` → труба пониженного давления

Эталон Бушуева (ч.3). Демонстрирует механику «расхождение трендов → недостающий
фактор».

**ИЛИ-ИЛИ.** Молниеотвод-проводник защищает антенну радиотелескопа под куполом, НО
проводник задерживает радиоволны (радиотень). Проводник нужен / проводник вреден.

**Размерности.** Электрическая прочность воздуха `[В/м]` = `L¹T⁻²` (разность
потенциалов `L²T⁻²`, делённая на длину); проводимость штыря = `L⁻¹T¹`.

**И-И.** `L¹T⁻² · L⁻¹T¹ = L⁰T⁻¹`, `S = −1` → ⬜ верхний серый.

**Расхождение (баланс).** Давление `L²T⁻⁴` лежит на голубом тренде `S=−2`.
Серый (`−1`) ≠ голубой (`−2`) → неучтён фактор.

**Недостающий фактор.** Переход серый(`−1`)→голубой(`−2`): домножить `L⁰T⁻¹` на
`L⁰T⁻¹` → `L⁰T⁻²` (голубой). Ячейка-множитель `L⁰T⁻¹` = **частота** → недостающий
фактор = частота ЭМ-излучения радиотелескопа.

**Формулировка.** Решение читается через давление (голубой) при учёте частоты:
**молниеотвод из диэлектрической трубы с пониженным давлением** (газоразрядная
трубка: ионизуется при разряде, прозрачна для радиоволн).
