# Пример: горячий шлак → `L³T⁻⁴` → пена

Эталон Бушуева (ч.3). Совпадает с ответом Альтшуллера (пена).

**ИЛИ-ИЛИ.** Макро-ФП: слой воздуха в ОЗ должен быть заполнен нетеплопроводным
веществом (уменьшить охлаждение шлака) И не должен быть заполнен (не мешать
заливу/сливу). Следствия: корка тонкая + непрочная.

**Две модели исходных факторов:**
- Лабковский: предел прочности σв = давление `L²T⁻⁴`; толщина корки = длина `L¹T⁰`.
  → `L²T⁻⁴ · L¹T⁰ = L³T⁻⁴`, `S = −1` → ⬜ верхний серый.
- Альтшуллер: теплопроводность `L⁻¹T⁻¹` (добавление Бушуева); толщина `L¹T⁰`.
  → `L⁻¹T⁻¹ · L¹T⁰ = L⁰T⁻¹`, `S = −1` → ⬜ верхний серый.

Обе модели → один серый тренд `S=−1` (подтверждение баланса).

**Икс-элемент.** На сером тренде столбец `L³` → `L³T⁻⁴` = **поверхностное натяжение**
(капиллярно-пористая структура). Контроль: плотность `L⁰T⁻²` как *входной* фактор ×
толщина `L¹T⁰ = L¹T⁻²` (`S=−1`) → снова к `L³T⁻⁴`. (Плотность `L⁰T⁻²`, `S=−2`,
нельзя брать как выход — иной, голубой тренд; только как вход.)

**Формулировка.** `L³T⁻⁴` = поверхностное натяжение → капиллярно-пористая структура
→ **пена**.
